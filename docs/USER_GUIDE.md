# Руководство пользователя Порог

## Установка

Распакуйте дистрибутив. Установщик принимает корневую папку с каталогами `Service` и `Desktop`; запускать `.exe` прямо из ZIP нельзя. В PowerShell администратора выполните `./scripts/Install.ps1`.

Приложение рассчитано на личный компьютер и одну учётную запись. При UAC под тем же пользователем дополнительная настройка не нужна. При вводе пароля другого администратора передайте SID пользователя через `-OwnerSid`. Получить SID можно через `whoami /user` до повышения прав.

Установка создаёт:

- службу `Porog` с автоматическим запуском и восстановлением после сбоя;
- файлы в `%ProgramFiles%\Porog`;
- данные и резервные копии в `%ProgramData%\Porog`;
- задачу `Porog Desktop` для запуска UI при входе владельца с обычными правами;
- ярлык в меню «Пуск».

Пользователь получает чтение данных; изменять защищённую конфигурацию может служба через IPC. Повторная установка при работающей службе отклоняется. Для обновления дождитесь окончания блока, удалите приложение и установите новую сборку; данные сохраняются.

## Политика PowerShell

Если выполнение `.ps1` запрещено, сначала проверьте `Get-ExecutionPolicy -List`. На личном компьютере можно разрешить локальные сценарии только для текущего окна: `Set-ExecutionPolicy -Scope Process RemoteSigned`. Скачанные сценарии сначала просмотрите и при доверии разблокируйте через свойства файла. Групповые политики корпоративного компьютера не обходите. Скрипты не изменяют политику выполнения автоматически.

## Первый рабочий промежуток

Откройте «Расписание» → «Новый промежуток». Введите название, необязательное намерение, дату и время начала и окончания. Время отображается в часовом поясе Windows; служба хранит абсолютное время со смещением UTC.

В поле сайтов укажите домены по одному на строку, например:

```text
youtube.com
www.youtube.com
m.youtube.com
vk.com
www.vk.com
dzen.ru
www.dzen.ru
```

Схемы `https://`, пути, порты и `*` не допускаются. Каждый поддомен задаётся явно; hosts не поддерживает wildcard. Международные имена преобразуются в IDNA.

В поле приложений укажите имена исполняемых файлов, например `Telegram.exe` и `MyGame.exe`. Путь к файлу не нужен. Системные имена, собственные компоненты Porog и браузеры целиком запрещены. До старта сохраните работу в выбранных приложениях: процессы будут принудительно завершаться и при повторном запуске.

Сохраните расписание. Пересекающиеся включённые интервалы отклоняются; соседние разрешены. Интервал может переходить через полночь, если дата окончания позже даты начала. Подготовленное вечером расписание выполнится на следующий день при работающей службе.

За минуту появится уведомление Windows. Его отображение зависит от настроек уведомлений ОС. В активном блоке «Обзор» показывает «Закрыто до HH:MM» и остаток. Изменить, удалить, выключить или сократить начатый промежуток через приложение нельзя. После окончания ограничения снимаются автоматически.

## Отход

В разделе «Отход» выберите целое число минут от 3 до 12 и нажмите «Начать отход». Окна на всех подключённых мониторах показывают таймер и предлагают встать, пройтись, выпить воды. Пропуска нет. Источник времени окончания — служба.

Повторный запуск UI восстанавливает незавершённый «Отход». При временной потере связи окно продолжает отсчёт до ранее полученного срока. Обычное закрытие окна блокируется; системные механизмы Windows не перехватываются. Если UI аварийно завершён, полноэкранного окна до его перезапуска нет. Изменение системных часов администратором также не защищено.

## Трей и перезапуск

Крестик главного окна скрывает его в трей. Двойной щелчок по значку открывает окно. Команда «Выход из интерфейса» завершает UI, но не службу; во время отображаемого «Отхода» она недоступна.

После перезапуска служба вычисляет текущее состояние по расписанию. Если компьютер включён в середине интервала, блокировка применяется сразу. Если интервал полностью прошёл при выключенной ОС, он не выполняется задним числом.

## Диагностика

| Сообщение | Что проверить |
|---|---|
| Служба недоступна | `Get-Service Porog`; совпадает ли SID владельца; повторное подключение |
| `HOSTS_WRITE_FAILED` | Права службы, доступ к hosts, корректность собственных маркеров |
| `PROCESS_CONTROL_FAILED` | Права доступа к выбранному процессу, его владельца и защищённость |
| `CONFIG_CORRUPTED` | Конфигурацию и `.bak`; примените явное восстановление |
| `CONFIG_VERSION_CONFLICT` | Откройте расписание заново, чтобы получить актуальную версию |
| `SCHEDULE_CONFLICT` | Время пересечения включённых промежутков |
| `ACTIVE_SESSION_LOCKED` | Дождитесь конца начатого промежутка |

Диагностика отображает доступность hosts, контроля процессов и перерыва. Статус доступности hosts означает возможность применить файл, а не доказательство блокировки всех браузеров. Посещения сайтов не регистрируются. События службы доступны в системном журнале Windows, без истории посещений.

## Восстановление

Администратор может выполнить установленный или исходный `scripts/Repair.ps1 -Target Config`, `-Target Runtime` или `-Target Hosts`. Сценарий останавливает службу и:

- для JSON сохраняет повреждённый оригинал с суффиксом `.corrupt.<timestamp>` и явно возвращает `.bak`;
- для hosts удаляет только корректный блок `BEGIN POROG V1` / `END POROG V1` и сохраняет чужие строки;
- запускает службу, которая повторно валидирует данные.

Резервная копия содержит предыдущую успешно записанную версию; при первом сохранении `.bak` ещё нет. Если копия отсутствует или некорректна, автоматического сброса нет. Исправьте файл вручную с сохранением оригинала. Некорректные маркеры hosts также требуют ручного просмотра. Не возвращайте старую полную копию hosts поверх чужих новых записей.

При остановке службы контроль процессов прекращается, а уже записанный блок hosts может оставаться до окончания, рассчитанного после перезапуска, либо до административной очистки. Потеря связи отражается в UI.

## Удаление

Дождитесь конца рабочего блока и «Отхода». В PowerShell администратора запустите `./scripts/Uninstall.ps1`. Проверка состояния требует SID владельца. Если служба повреждена или административная учётная запись отличается, предусмотрено явное восстановительное удаление `./scripts/Uninstall.ps1 -Recovery`.

Удаление останавливает службу, снимает только собственные записи hosts, удаляет задачу автозапуска и программные файлы. Конфигурация, состояние и резервные копии остаются в `%ProgramData%\Porog`. Их можно удалить отдельно после проверки. Наличие `-Recovery` не является обычной кнопкой отмены и требует прав администратора.
